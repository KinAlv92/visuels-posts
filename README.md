# visuels-posts

Images utilisées dans les posts LinkedIn, X et Threads.

## Organisation

- Un dossier par projet, par exemple `corde-a-sauter/`.
- Noms de fichiers en minuscules, sans espaces ni accents : `corde-a-sauter-01.png`.

## Lien direct d'une image

```
https://raw.githubusercontent.com/KinAlv92/visuels-posts/main/<dossier>/<fichier>
```

C'est ce lien qui va dans la colonne « Visuel » du calendrier éditorial.
